# JeeSign Studio - Portfolio

Website portfolio sederhana yang dibuat untuk tugas Slicing Website HTML, CSS, dan JavaScript.

## Tentang Website

JeeSign Studio adalah portfolio sederhana yang menampilkan profil, kemampuan, dan beberapa karya yang saya buat.

Website ini dibuat menggunakan:

- HTML
- CSS
- JavaScript
- DOM

CSS yang digunakan merupakan Plain CSS tanpa menggunakan Bootstrap atau Tailwind.

## Fitur

- Responsive untuk desktop, tablet, dan mobile
- Navbar
- Menu mobile
- Tombol menuju bagian project
- Section About
- Section Skills
- Section Projects
- Section Contact

## Penerapan JavaScript DOM

JavaScript digunakan untuk memberikan interaksi sederhana pada website.

Contohnya:
- Membuka dan menutup menu pada tampilan mobile
- Tombol "Lihat Project" untuk menuju bagian project

DOM digunakan untuk mengambil elemen HTML dan memberikan aksi ketika elemen tersebut digunakan.
